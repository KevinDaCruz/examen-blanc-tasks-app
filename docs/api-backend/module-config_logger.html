Module: config/logger

Journalisation applicative centralisée avec Winston (remplace les console.log). - Développement : sortie console colorée et lisible. - Pré-production / production : sortie JSON structurée sur stdout (collectée par Docker / l'hébergeur / Loki), et optionnellement dans des fichiers si `LOG_DIR` est défini (`error.log` pour les erreurs, `combined.log` pour tout, `audit.log` pour les événements de sécurité), avec rotation par taille. - Le niveau `http` reçoit les logs d'accès produits par morgan.
