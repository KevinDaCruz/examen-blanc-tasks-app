Module: config/env

Chargement et validation des variables d'environnement. Les secrets (URI MongoDB, clé JWT…) ne sont JAMAIS écrits dans le code : ils viennent du fichier `.env` en local (non versionné, cf. `.gitignore`) et des variables / secrets de l'hébergeur ou de la CI en pré-production et en production. Le serveur refuse de démarrer si la configuration est absente ou trop faible (fail fast) plutôt que de tourner avec un secret prévisible.
