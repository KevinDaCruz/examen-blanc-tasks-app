Module: middleware/metrics

Métriques Prometheus (supervision E26). Expose sur `GET /metrics` (non publié par le reverse-proxy) : - les métriques Node.js par défaut (CPU, mémoire, event loop, GC…), - `http_requests_total{method,route,status_code}` : compteur de requêtes, - `http_request_duration_seconds{method,route,status_code}` : histogramme de latence. - `auth_login_failures_total` : échecs de connexion (détection de brute force). Ces séries alimentent les alertes « API down », « latence p95 > 500 ms » et « taux d'erreurs 5xx > 5 % » (voir `monitoring/prometheus/alert.rules.yml`).
