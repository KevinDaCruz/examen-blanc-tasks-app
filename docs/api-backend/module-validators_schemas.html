Module: validators/schemas

Schémas Joi de validation des entrées utilisateur. Toute donnée venant du client est validée AVANT d'atteindre la base : - types imposés (une chaîne reste une chaîne => bloque l'injection NoSQL `{"$ne": null}`), - longueurs bornées (pas de champs vides ni de payloads énormes), - balises HTML refusées (prévention XSS stockée), - champs inconnus rejetés (pas de mass-assignment, ex: changer le champ `user`).
