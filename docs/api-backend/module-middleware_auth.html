Methods

(inner) auth()

Vérifie le JWT et expose l'utilisateur dans `req.user` (`{ id }`). Le token est lu dans un cookie **HttpOnly** (inaccessible au JavaScript du navigateur, donc non volable via une faille XSS) au lieu de `localStorage`. L'algorithme est imposé (`HS256`) pour éviter les attaques par confusion d'algorithme. Réponses : 401 si le token est absent, invalide ou expiré (avant : 418 « I'm a teapot »).
