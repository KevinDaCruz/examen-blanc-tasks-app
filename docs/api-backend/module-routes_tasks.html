Module: routes/tasks

Routes CRUD des tâches de l'utilisateur connecté. Toutes les routes exigent une session valide (middleware `auth`). Contrôle d'accès (correction IDOR) : chaque requête filtre sur `{ _id, user: req.user.id }`. Une tâche appartenant à un autre utilisateur est donc traitée exactement comme une tâche inexistante (404), sans révéler son existence.
