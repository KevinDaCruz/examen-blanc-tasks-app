Methods

(inner) validate(schema, sourceopt) → {express.RequestHandler}

Crée un middleware qui valide `req[source]` avec un schéma Joi. En cas d'erreur, répond 400 avec le premier message lisible ; sinon remplace `req[source]` par la valeur nettoyée (trim, conversion de types, champs inconnus rejetés).
Parameters:
Name Type Attributes Default Description
schema Joi.ObjectSchema Schéma Joi à appliquer.
source 'body' | 'params' <optional>
 'body' Partie de la requête à valider.
