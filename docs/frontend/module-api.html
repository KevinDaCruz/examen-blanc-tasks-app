(inner, constant) api

Instance axios configurée pour l'API. - `baseURL` : vient de `VITE_API_URL` (différent par environnement : dev, pré-prod, prod). Par défaut `/api` : même origine, proxifiée par Vite en dev et par nginx en production. (Avant : `http://localhost:5000/api` en dur, inutilisable une fois déployé.) - `withCredentials` : envoie le cookie de session HttpOnly. Le token n'est plus stocké dans `localStorage` ni ajouté à la main dans un en-tête.
